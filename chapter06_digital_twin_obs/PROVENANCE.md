# Chapter 06 provenance

The original OBS program was manually written by the author without AI code generation, as reported by the author. Source files are copied from the audit stage, which was hash-matched to the backup OBS project. Its parent Git worktree did not track the OBS `Code/` files. The later `later_obs_p2p_300_replay.py` was Codex-assisted and has not generated any thesis-era data.

This package copied 1569 chapter files without changing their bytes. The source alias and relative path for each file appear in the top-level [file manifest](../GITHUB_FILE_MANIFEST.csv). Git commit information, where known, is contextual; a commit date alone does not prove that a specific file was used in the submitted dissertation. File hashes prove copy integrity, not experimental reproduction. Any later verification or replay program is identified separately from historical research code.
